# WeCharge — Sensorless Dynamic Wireless Charging

**WeCharge** — безсенсорна динамічна бездротова зарядка електротранспорту та мобільної техніки під час руху.

Hybrid inductive + capacitive coupling in one transmitter segment: the coupling capacitor acts as a self-activating switch, so the segment turns on only when the receiver is above it — no position sensors needed. Protected by patent **LV 15706 B1**.

Chernihiv Polytechnic National University, Ukraine
